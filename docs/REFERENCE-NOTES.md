## 可靠文字依据

主要采用[泉州市人民政府开元寺专题](https://www.quanzhou.gov.cn/lyb/lytj/rmjdtj/202202/t20220224_2699974.htm)，内容来源为世界遗产相关介绍。

- 东侧镇国塔：现存石塔建于1238–1250年，高48.27米。
- 西侧仁寿塔：现存石塔建于1228–1237年，高45.06米。
- 共同特征：五层八角楼阁式花岗岩石塔，塔座、塔身、塔顶和塔刹；逐层收分，门龛逐层错位，塔壁每层16尊浮雕，外设石栏檐廊。
- 结构差别：镇国塔每层柱间两组补间斗拱；仁寿塔第三至第五层柱间只有一组。
- 须弥座雕刻题材不同：东塔佛经故事，西塔花兽。当前程序模型只概括雕刻层次和轮廓，不能声称逐幅图像复原。
- 实际双塔相距约200米，见[泉州市人民政府重点文物介绍](https://www.quanzhou.gov.cn/lyb/lswh/zdww/201510/t20151029_183313.htm)。若模型缩短两塔间距方便并列展示，需要说明采用展示布局。

注意：其他介绍有48.24米、44.06米等口径；本项目统一采用上面的泉州市政府专题数值，不混用。

## 从照片提取的造型约束

1. 石构整体呈暖灰、灰褐色；强日照照片偏金黄，阴面偏中性灰。不要使用绿琉璃屋顶或红木柱。
2. 每层墙体为八角筒，角部有分段石柱；塔身收分克制，最低层相对高。
3. 五道宽檐横向伸展明显，坡度较缓；翘角存在，但程度小于原模板的装饰性飞檐。
4. 檐下具有厚而有层次的石制仿木构托架，深色区来自遮蔽阴影；不能只用薄屋面片替代。
5. 石栏有方柱、上扶手和浅浮雕实体栏板。首层基台外栏局部较开敞；高层不是木质透空栏杆。
6. 门洞与小龛交错，外有拱券或方框；左右是嵌入式浅浮雕人物框。
7. 铁塔刹呈暗褐，轮盘与球形段上下串联；有从高处向八角檐顶张开的细链条。
8. 浮雕需要用低浮起的几何轮廓交代，不宜拿简单大球当石狮或装饰动物代替建筑本体雕刻。

## 不采用的参考

- 旅游宣传合成图、夜景滤镜图：色彩和轮廓容易受加工影响。
- 城市天际线远景：可作位置关系辅助，单塔细节不足。
- 单张广角仰视：不能据其像素比直接推导各层真实尺寸。
- 政府页面的实景图可佐证结构，但未查到独立开放许可，最终展示参考图优先使用已明确许可的Commons照片。
