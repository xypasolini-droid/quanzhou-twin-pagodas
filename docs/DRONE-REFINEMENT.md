# 航拍核对与本轮细化

更新于2026-11-05。保留原有22秒营造流程：台基、五层塔身、塔刹依次组成；播放、暂停、倒拖、阶段定位与重演继续沿用。研究按层整理证据，界面仍以整体营造与构造近观展开，不增加逐层人物导览。

## 实拍如何使用

用户提供的四个视频均为3840×2160、约59.94fps的HEVC素材，色彩元数据为BT.709 SDR。按原有色彩空间抽取远景和近景，没有额外套用滤镜。两份0087视频的大小、流信息以及首、中、尾抽样一致，因此仅对其中一份重复取样；这不是全文件哈希相同的断言。

重点核对0086的00:17、00:33、00:49和0087的00:07、00:31：砌石、门龛、石柱、石栏、斗拱、石檐，以及六处能读出体态的人物局部。航拍没有连续交代每个近景的层号和方位，未据此猜测人物身份或为每层编排故事。

航拍及抽帧只用于本地观察，不作为应用贴图或公开下载资源。模型仍是程序几何，不是摄影测量、点云或逐石扫描。

## 据影像校正的差别

- 石材保留冷灰、暖灰与局部赭褐块石差异；屋面偏冷，石栏边框较浅。风化斑和竖向水迹采用多尺度程序纹理，不把夕阳的整体金黄色铺成材质底色。
- 石柱分段并改为近圆截面；方龛增加封砌背板，拱门保留半月形石额与矩形门口的层次；石栏更低厚，边框更浅。
- 石斗拱横臂增加弧切与承托关系，石屋面增加长条接节与端部差异；顶层屋面压低，塔刹随之调整，双塔高度比保持48.27∶45.06。
- 人物按浅刻长袍与较厚甲胄区别体块；压薄头光和衣纹，去除统一的圆管笑脸。借助有编号的研究图版补充合掌、持刀、骑兽与坐读等代表构图。采用位置和未覆盖范围见[雕刻研究记录](SCULPTURE-RESEARCH.md)。

照片里的亮暗同时包含光照、材质与风化。没有色卡、现场尺寸或扫描数据，因此颜色与相对深浅是观察性校正，不能视为实测的反射率或雕刻深度。

## 阅读与画面

“双塔小志”补充寺院沿革、两塔前身与南宋石塔年代、石构差别、时间线和保护记录；事实通过数字链接指向出处。详见[历史来源](HISTORY-SOURCES.md)。

“日光 / 斜阳”改变灯光，不更换石材底色。落成后桌面端增加局部接触遮蔽，让石缝、衣纹和斗拱交接更易辨认；营造中和窄屏不启用这一额外遮蔽通道。阴影继续使用与构件相同的营造变形，避免动画中留下完整塔影。

交互参考 `modern-web-guidance` 检索到的CSS、motion、performance建议：使用原生按钮、可键盘切换的标签页和原生展开段落，窄屏上下排布；减少动态偏好下取消相机缓动；静止场景不重复重绘。没有为了侧栏增加新的界面运行依赖。

技术核对：[Three.js颜色管理](https://threejs.org/manual/en/color-management.html)、[GTAOPass](https://threejs.org/docs/pages/GTAOPass.html)、[MeshStandardMaterial](https://threejs.org/docs/pages/MeshStandardMaterial.html)。颜色贴图使用sRGB，凹凸和粗糙度按非颜色数据处理，后期输出经OutputPass。

## 范围

原营造动画表达的是构件展示次序，不断言历史施工工法；双塔间距、周围绿植仍采用展陈布局。各层已找到代表研究图版，不等于全部160尊、每个面和每个细节均已复原。未确认的形状保留概括，研究中的缺页与现代近照缺口均在索引中注明。
