# 双塔交互展陈设计简报

- 产品：泉州开元寺东西双塔三维营造展示；观者可自由环视、切换近景和拖动营造进度。
- 平台：React + Vite + Three.js 单页浏览器应用，桌面 Chrome 优先，320 CSS px 以上响应布局；键鼠与触摸均保留可替代操作按钮。
- 已有基础：沿用 threejs-architecture-effects 的按材质合批、逐构件 GPU 时间轴、同步阴影和按需渲染。
- 事实依据：泉州市政府开元寺介绍核实八角五层、塔高与年代；Commons 实拍核对体量材质；用户提供泉州文旅剖面文章用于形制校核。
- 可观察成功：首屏看清两座完整石塔，能暂停、倒拖、重演和切换单塔/斗拱/塔基；参考来源可打开。
- 范围：外观与主要构造展示；石刻浮雕简化；并置间距不同于真实约200米塔院，不承诺文物测绘精度；不部署。

## 方向合约

- 主张：像一张可操作的古建图录，把最大视觉面积留给石塔。
- 调色：纸底#f4f1e9；浅底#faf8f3；石墨#353b35；辅助#73786c；分隔#d9dbcf；朱砂#9b4c39；操作深绿#414f44。
- 排版：本地宋体用于标题与塔名，无外部字体依赖；系统无衬线用于控制与数字。
- 构图：细页眉 → 简洁展题 → 双塔大画布 → 观赏视角 → 营造时间轴 → 来源入口。
- 识别点：东西两塔并置且高度不同，七个可定位的建造阶段；其余界面保持安静。
- 挑战结论：不使用泛化营销卡片、数据看板或钟楼装饰；塔高、日期和阶段标签均有用途。
- 动效：首次展示完整建筑，用户启动后播放22秒营造；支持暂停、速度、回拖；减少动态时相机即时定位。
- 状态：准备中、完成、播放、暂停、拖动、相机切换、WebGL失败和恢复、参考说明对话框。
- 验证：TypeScript/Vite构建；桌面/窄屏实际截图；浏览器日志；建造0/中段/1与倒拖；相机与来源窗口、键盘焦点。
