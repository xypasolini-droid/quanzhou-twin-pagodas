# 双塔展示验证记录

验证日期：2026-11-05。macOS本机Chrome，实际打开Vite生产构建 `http://127.0.0.1:5179/`。本记录覆盖160处人物资料驱动细化这一版；未变的历史侧栏与响应式界面沿用前轮核验。

## 构建与交互

- `npm run build`：TypeScript与Vite构建通过；主脚本约1,066 KB，gzip约270 KB（新增160条证据数据与几何分支）。Vite仍提示大包，未为了消除提示拆包。
- 原22秒营造流程保留。实际从0播放到100%自动停止；另一轮以2倍速在约45%暂停；阶段按钮跳至58%，键盘Home回0、End回100%均正常。半成品与阴影同步，没有残留完整塔影。
- 桌面1702×849无横向溢出；原营造控制区可见。双塔、单塔、石檐、人物、塔座视角和旋转、缩放、重置可用。东西塔人物近景各有明确目标，最终模型的东塔骑兽及西塔坐读形态已在浏览器查看。
- 日光/斜阳切换可见照明变化；石材保持同一套底色。静止相机最终停止重绘。
- 历史侧栏的三个标签页支持左右键及Home/End；东西塔切换更新资料和相机。原生时间线段落可展开；资料数字链接指向来源。没有逐层人物导览。
- 390×844、320×740无横向溢出；320px下文档scrollWidth为320，时间轴真实命中高度28px。模型、播放控制与历史侧栏上下排列，页面和侧栏可滚动阅读。临时视口设置已恢复。
- 最终生产页面未观察到JavaScript错误或Three.js告警。

## 几何与本机性能

- 塔身建筑：26,614逻辑构件，989,798三角面，6个材质合批网格；顶点均有限；最高点31.90，营造排程最迟0.993完成。
- 加展台与植物后共26,854个逻辑构件。桌面静态近景有接触遮蔽后期；抽样为21—27次绘制、约204—303万三角面（是否包含当帧阴影更新会改变计数，包含后期重绘，非独立几何数量），33个纹理、9个几何对象。
- 原营造过程抽样约60fps；阴影约24次/秒。静止近景 `renderFps=0`、`idle=true`。帧率只代表本机抽样，不是低端手机性能承诺。
- 桌面像素比最高1.5，窄屏1.25；接触遮蔽只在桌面且完全落成后开启。营造中及窄屏保留基础渲染与输出通道。

## 研究与表达范围

- 东西塔各五层均已找到并查看代表研究图版，另以航拍及现代照片核对。原书扫描有重复、裁切及缺页，不能称为完整160尊高清正射档案。
- 160处各有独立来源数据：121处图像参照、39处文字补形；图像包含历史照片、现代远摄和局部残幅。
- 独立生成并比较160处局部几何，得到144种位置几何组合，11组资料相同或差异不足的轮廓保留相同形状（16个重复实例）。没有按编号随机变化。
- 全部160尊已输出正面核对图，复核左右、握点、横杵越框、裸胸/甲胄、鸟笼从者及坐读构图。严格边框检查无越框告警，全部顶点有限。仍不是面部、指尖、衣纹的逐点扫描复原。
- `App.tsx`、`PagodaThreeScene.tsx`、`builder.ts`、`style.css`与上轮提交逐字节相同。建筑文件仅替换人物函数及两个导入，22秒阶段排程保持不变。
- 材质是观察性校色，没有色卡或现场反射率测量；旧黑白照片不承担现状颜色判断。
- 双塔间距与绿植为展陈布局，营造动画是构件呈现次序，非已证实的历史工法。
- 仅验证Chrome及窄屏模拟，未验证真实iPhone/Android硬件或Safari。
- 用户航拍与研究扫描图不包含在公开资源；出处及缺口见 `../SCULPTURE-RESEARCH.md`。
