# 双塔展示验证记录

验证日期：2026-11-05。macOS 本机 Chrome，实际打开 Vite 生产构建 `http://127.0.0.1:5179/`。

## 结果

- `npm run build`：TypeScript 与 Vite 构建通过。主脚本约823 KB，gzip约225 KB；Vite保留大包体积提示，尚未拆包。
- 桌面1702×849：双塔全景、完整塔刹、底座和控制区可见；无横向溢出。
- 窄屏390×844、320×740：无横向溢出；视角按钮重排为两行，页面可纵向滚动；320px的页面宽度和scrollWidth均为320px。
- 播放：从0开始，31%附近暂停，2倍速续播至100%后自动停止；进度键盘Home回到0、End回到1，阶段按钮跳到58%状态正常。半成品墙体和阴影随营造进度同步变化。
- 相机：全景、单塔、斗拱、人物和塔座近观可用；拖动、旋转、缩放、重置均可操作。低角度近观可到达目标并停止重绘。
- 参考窗口：两张本地实景图片实际加载，naturalWidth均1200；有来源和许可链接。Escape关闭后焦点回到来源按钮。
- 控件：按钮具可读名称和焦点样式；时间轴真实命中高度28px，支持键盘；移动端画面外控制可滚动到达。
- 最终页面未观察到JavaScript错误。开发中出现的已弃用PCFSoftShadowMap和环境模糊采样告警已修正为PCFShadowMap及较小采样半径。

## 几何及性能观察

- 纯建筑与展台：20,932个逻辑构件，675,102三角面，7个材质合批网格；几何检查所有顶点有限；最高点33，营造最迟0.993完成。
- 加植物与接地平面后：21,130个逻辑构件，706,052个可见三角面，9次常规绘制。阴影更新时为16次绘制/约138万三角面；单方向光阴影，无后期通道。
- 本机桌面播放抽样约60帧/秒，阴影约24次/秒；静止后renderFps为0。抽样仅代表本机，不是移动设备性能承诺。

## 仍有的表达边界

- 模型是基于照片与构造图的解释性重建，不是测绘、扫描或文物修复模型。
- 160处人物石刻使用多类浅浮雕意象，并非逐尊写实刻画或精确方位定位；塔座故事图用装饰轮廓概括。
- 双塔间距及绿植为展陈布局；施工动画是构件呈现次序，不宣称真实历史工法。
- 已验证Chrome窄屏布局，未做真实iPhone/Android硬件和Safari兼容性验证。
- kknews补充文章受访问验证阻挡，没有读取正文或图片，也没有冒称采用其内容。
